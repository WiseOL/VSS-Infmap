v36: Tank Track Tool compatibility

Supports the installed Workshop item 737640184 and ACF-Team/TankTrackTool revision 68bf8e7. All 33 Workshop Lua files matched that GitHub checkout after newline normalization. The three adapted files are guarded by original-source CRCs; other revisions are skipped with a console message rather than silently replacing different code. Keep Tank Track Tool installed: this package contains only its compatibility adapter, not its complete models/materials.

Fixes:
- Legacy chassis matrices and linked wheel positions use the same live viewer frame.
- Automatic/legacy clientside wheel/lighting models draw in localized native frames instead of feeding remote coordinates into InfMap's SetPos clamp.
- Cached automatic wheel positions and track matrices rebase when the viewer changes chunk between Think and Draw.
- Automatic scrolling history rebases with the viewer frame to avoid treating a chunk jump as vehicle travel.
- Only automatic visual suspension probes use a scoped native-chunk hull adapter; HUD and other addon traces are unchanged.
- Existing shared entity, P2M, ACF and Wire rendering fixes remain included.

Install: replace addons/infmap with the infmap folder in this archive. Keep the existing Tank Track Tool addon. Fully restart server and reconnect clients. Look for:
[InfMap tracks v36] Workshop/GitHub automatic and legacy rendering installed.

Revision 15: regular prop buoyancy in InfMap custom water.

The original map simulates water separately from native Source water volumes.
Its prop buoyancy only recognized a fixed physics-material list, ignored tool
SetBuoyancyRatio changes, used an unrotated height rejection check, and forcibly
slept submerged props. Small props could also settle completely below the
visible surface because lift used a fixed depth scale rather than their size.

The water simulation now reads GetBuoyancyRatio where supported. It also tracks
explicit SetBuoyancyRatio calls in a weak-key physics-object map so tool changes
work on branches lacking that getter. Explicit zero disables lift. On branches
without getter information, existing material/airboat defaults remain fallback.
The native setter still runs. Standard prop_* classes retain the original
water simulation eligibility; this does not add naval-compartment support.

WorldSpaceAABB is used to reject dry props correctly when rotated. Eight OBB
corner samples remain, but immersion is scaled to the rotated vertical size.
Maximum full-immersion lift is twice body weight at ratio 1, multiplied by the
chosen buoyancy ratio. Each corner contributes mass*gravity*dt*ratio/4 times
its immersion factor. Drag and angular damping are timestep-scaled. This is
an approximate custom-water buoyancy model, not exact displaced mesh volume.
Frozen props are skipped; props are no longer forcibly put to sleep by water.
Water height, collision groups, no-collide/physgun handling, land physics,
explosion damage, and the existing compatibility fixes are unchanged.

Replace the combined addon folder, fully restart and reconnect. Reapply the
buoyancy tool to test props after restarting. Test a wood/barrel prop, a metal
prop with buoyancy set to 1, a zero-buoyancy prop and a rotated long prop. Props
whose native buoyancy is zero are still expected to sink until made buoyant.

Tests: actual server hook in a mocked API; tool-set positive/zero buoyancy;
missing getter fallback; native getter values; dry and frozen exclusion;
rotated immersion; no forced sleep; impulse scaling and simplified 20-second
settling integration at 30/66/100 Hz. Collision/P2M, camera and crew regression
checks passed. No live GMod server test was performed. Keep v14 as rollback.

CORRECTIONS
v30 explicit rendering avoided the cached child matrix, but the RenderScene
culling bounds STILL projected the cached child GetPos. A displaced cached
position could therefore cull the actual mesh incorrectly. P2M bounds now use
the same parent-composed native position and live root chunk as the draw.

for an unparented root, rather than relying on an InfMap_GetPos alias. Other
entity culling paths retain existing behavior. No guessing/normalizing positions
by their numeric magnitude, no server teleporting, and no server physics changes.
